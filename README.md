# 💍 Ananta Sutra — Wedding Landing Page

A premium, modern wedding services landing page built with **Next.js 15**, **React 19**, **TypeScript**, and **TailwindCSS v4**. Designed to showcase wedding photography, videography, and event planning services with an elegant, responsive UI.

---

## ✨ Features

- 🎨 **Stunning Hero Section** — Full-screen cinematic banner with animated tagline
- 📸 **Gallery Section** — Lightbox-enabled photo gallery with smooth transitions
- 🎥 **Video Modal** — Embedded video showcase for wedding films
- 💼 **Services Section** — Detailed service cards (Photography, Videography, Planning, etc.)
- 📊 **Stats Band** — Animated counters showcasing experience & milestones
- 🌿 **Our Story** — Brand story section with elegant typography
- 📖 **Journal / Blog** — Latest updates and wedding tips
- 💬 **Testimonials** — Client reviews carousel
- 📩 **Enquiry Modal** — Lead capture form with validation
- 📞 **WhatsApp Button** — Floating WhatsApp quick-contact button
- 🔗 **Sticky Navbar** — Smooth-scroll navigation with mobile hamburger menu
- 📬 **Contact Section** — Full contact form with social links
- 🦶 **Footer** — Complete footer with links, social media, and branding

## 🚀 Getting Started

### Prerequisites

- **Node.js** v18+ 
- **npm** or **yarn**

### Installation

```bash
# Clone the repository
git clone https://github.com/kunaltyagi18/wedding-landing_page.git

# Navigate to the project directory
cd wedding-landing_page

# Install dependencies
npm install
```

### Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
npm run start
```

### Linting & Formatting

```bash
# Lint
npm run lint

# Format with Prettier
npm run format
```
